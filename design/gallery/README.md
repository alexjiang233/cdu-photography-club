## 首页：整屏照片墙

- **七行**照片墙铺满 100svh，行高 = 视口 / 7，上下不留白。
- 所有照片**统一裁成 3:2**（1200×800），同一行里等高，整体像一面整齐的灯箱墙。
- 奇数行向左、偶数行向右，速度不同（84s / 104s），并给每行设了负延迟，避免所有行同时到达同一张。
- 墙面不透明度 0.88，上面再压一层双向渐变遮罩（左侧 66% 保证标题可读，上下 58% → 34% → 74%）。
- 标语用协会自己的：**摄录人间万象 / 聚焦永恒瞬间**，衬线、字距 0.14em。
- 素材来自 `D://成都大学-文件归档//Pictures//示例作品`，15 张里选了 13 张。
- `prefers-reduced-motion: reduce` 时停止滚动。

**注意**：3:2 是裁切后的比例，原图有竖幅、有方幅，裁切位置居中；如果某张构图被切坏，换一张或单独指定焦点。

## 照片墙

位置：首页 hero 之后，整幅出血，两排。

- 上排向左、下排向右，速度不同（68s / 84s），避免两排同频。
- 每格高度在 232 / 268 / 344 / 372 之间交错，并上下偏移 ±16px，所以**上下边缘是锯齿**，不是一条直线。
- 悬停暂停，方便看某一张。
- 无缝循环：JS 把每排内容复制一份，动画位移 `-50%`，正好接回。
- `prefers-reduced-motion` 下停止滚动，改为可横向拖动。
- 内容混排：四幅作品 + 四张 2024.06.04 的现场照。**现场照有人脸，未确认授权。**

| 页面 | 任务 | 内容 |

## 视觉

- 纸白 `#F4F1E9`、墨 `#14120E`、正红 `#F20A0A`（Logo 原始色）。
- 衬线做标题与正文，无衬线 + 大字距做标签与编号。
- 12 栏、最大 1320、页边 `clamp(24px, 5vw, 80px)`。
- 红色只出现在：区块编号的斜杠、活动序号悬停、页脚无。
- 纸纹 5%（`feTurbulence`），只在大色块上看得出来。
- 没有圆角、没有投影、没有渐变按钮、没有卡片。

**作品墙是不对称的**：7 / 4 / 4 / 7 栏，第二幅下沉 46px、第四幅下沉 82px。像挂画，不像网格。

## 已知缺口

1. **作者没署名**：四幅作品的作者需要你问出来，展签才能完整。
2. **视频会耗流量**：移动端应切成首帧图。
3. **活动没有配图**：只有一场（2024.06.04）有现场照片，其余没有，所以活动页保持纯文字。
4. **字体 43 MB**：原型直接引 `../catalogue/assets/*.ttf`，正式实现必须子集化。
5. **加入信息是占位**：群号、具体时间需要你补。
