# 展览式社刊

新版本入口 `/field-journal`；原版 `/` 保留。

## 内容与维护

- `/field-journal`：最新已发布且公开的一期，直接阅读。
- `/field-journal/issues`：各期封面和阅读入口。
- `/field-journal/issues/{id}`：单期固定地址，分享按钮复制此地址。
- `/field-journal/about`：协会介绍和联系二维码。
- `/admin/club/issue/`：新建社刊、添加有顺序的内容块、审核发布、撤下。
- `/admin/club/sitesettings/`：上传联系二维码及填写联系说明；没有提供二维码时如实显示。

新建一期，填写期号、中英文标题、封面、开场文字和署名。下方按顺序添加大幅照片、连续两项的并列照片、留白照片或文字段落。照片先经后台“文件”上传，沿用原图片处理流程与 EXIF 保留规则。署名留空不会编造作者。

保存后通过“在站点查看”打开草稿预览。预览需要当前浏览器有后台编辑权限；草稿 API 和图片不会向访客开放。列表先“提交审核”，再“审核通过并发布”。已发布内容先“撤回为草稿，准备修订”，再编辑；这会暂时撤下该期。归档也会撤下公开阅读。编辑角色可编排社刊，其他原角色权限不变。

图片大图支持上一张、下一张、键盘方向键、Esc、手机横滑。分享固定链接不包含预览参数。页面文字以纯文本渲染，不接收 HTML。

## 首期

“入夜以后 / After dark”使用现有公开作品系列的前四张照片。未导入海报，未更改原系列、原文件或旧页面数据。不虚构拍摄地点、经历或作者。

`prepare_first_issue --collection UUID` 是首次编排辅助命令，第一期已存在即退出，避免覆盖人工编辑。原版及本轮改版前的前端快照在本地 `.local-run/pre-exhibition/`。

## 视觉

展墙白 #fafbfc、文字 #16191c、说明 #60676e、细线 #dfe3e6、焦点蓝 #254dc5。中文使用系统黑体，英文/数字使用本地 Titillium Web。封面为两列构图，正文按照片原比例排列，大幅、留白、并列三种空间尺度；手机改为单列。公共样式在 globals.css 的 Exhibition journal 段，交互过渡在 motion.css，不引入额外样式或动效库。
