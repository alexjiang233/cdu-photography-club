# 画廊版本（当前）

入口 `/field-journal`。展示协会照片与活动，不称期刊、不强制按期组织、不设成员栏目。原网站 `/` 保留。

## 阅读

首页以协会真实合影为入口；恢复活动相册、已知日期的活动记录、胶片带。`/works` 展示照片组；`/activities` 展示活动相册与日期记录；`/about` 放介绍和二维码。旧 `/issues` 地址转到照片页。先前“入夜以后”已撤下，原占位系列标记 `is_placeholder`，新画廊通过 API `placeholder=0` 排除它；没有删除原照片。

相册详情展示选中的一张照片与拍摄信息，底部印样可切换。放大视图同样显示作者、拍摄时间、机身、镜头、快门、光圈与 ISO。缺失信息不编造；没有像素量。EXIF 时间是相机原始时钟，未自动校正。前台只读取技术参数白名单，不输出 GPS、序列号、相机所有者等字段；原图和 EXIF 继续保留。

## 维护

- 作品系列：照片可逐张补充摄影署名、时间和参数；留空使用原图 EXIF。
- 活动：直接填写开始/结束时间、地点与简短说明，下方添加活动照片，无须再新建一篇稿件或作品组。
- 文件：后台可查看提取的技术参数。新上传的图片自动提取参数。
- 网站设置：协会标识及联系二维码。
- 展览编排：保留之前的可选人工编排数据；新首页不依赖它。
