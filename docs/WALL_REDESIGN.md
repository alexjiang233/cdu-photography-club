# 滚动照片墙改版

参考 `design/gallery/`，未修改 DeepSeek 的原型。原网站 `/` 保留，新版仍为 `/field-journal`。

## 保留

七行反向缓慢滚动的封面、深浅场景切换、十二栏错落挂画、活动时间表、大图与展签、简短联系区。大标题沿用原型衬线字体的子集，小字使用黑体与本地 Titillium Web。

## 修正

- 使用现有公开数据，每组照片和每场活动链接到自己的详情页。
- 封面沿用原型十三张视觉样片并明确标注，不宣称是社员作品，也不导入数据库。
- 正文保留真实照片原比例，去掉重复的底部照片带；更多内容进入列表。
- 活动按后台日期倒序，不抄未核实的八场日期。
- 活动记录和相册使用独立分页，避免互相越界。
- 无缝循环在 React 中渲染完整重复段，间隙也参与循环；不用 innerHTML 复制。
- 提供暂停按钮；照片墙离屏或页面隐藏时自动暂停；尊重减少动效设置。
- 原型约 25 MB 的标题字体生成约 111 KB WOFF2 子集，保留源字体许可；没有复制另一套大字体。
- 小字号保持无衬线，主要说明字号 13–15px；展签保留摄影者、时间、机身、镜头与曝光参数，不显示像素量。
- 保留 EXIF、手动补录、印样选图、大图切换等既有功能。

## 文件

`photo-wall.tsx` 只负责背景墙与暂停；`event-rows.tsx` 共用活动行；`gallery-join.tsx` 共用联系内容。样式仍在 globals.css，动效仍在 motion.css。

封面样片位于 `frontend/public/gallery-wall/`，正式选片后替换这组资源。只有封面使用原型已裁切的背景图，正文不统一裁图。联系二维码在后台网站设置维护。

本轮修改前的页面及样式快照在 `.local-run/pre-wall-redesign/`。
