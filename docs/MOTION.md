# 动效与交互：印样 / 胶片带

本轮在原有交互上增加两个主要动作：横向翻看胶片、筛选后重新排片。保留纸白、墨、暗房红与照片原始比例，不引入动效库。

## 这一轮的变化

| Before | After | Why |
| --- | --- | --- |
| 首页也是六张静态网格，主要靠淡入和 hover | 横向胶片带，鼠标惯性拖拽、原生触控滚动、前后按钮与键盘浏览 | 让浏览动作与摄影的底片语境相连 |
| 筛选结果直接换位 | keyed 网格 FLIP，保留作品移动到新位置，新作品淡入 | 避免筛选时失去空间连续性 |
| 首屏只整体淡入 | 标题分行揭示、封面如相纸落位、正文错峰 | 首屏有层次，照片仍是重点 |
| 全页上移叠加每个区块上移 | 页面仅短淡入，区块与印样各司其职 | 减少重复位移 |
| 等待 load / idle / 3 秒兜底，再修改 class 隐藏内容 | useEffect 后用 WAAPI；CSS 默认不隐藏内容 | 避免延迟突然隐藏和水合类名冲突 |
| 首图不能放大，单张作品没有灯箱 | 首图与其余照片都能打开整组灯箱 | 修复实际断开的观看流程 |
| 灯箱直接关闭、切图重复淡入 | 从选中图片展开、方向切图、150ms 关闭、背景滚动锁 | 让大图观看更连贯 |
| 仅依赖系统减少动效偏好 | 跟随系统，并提供页脚开关与本地偏好保存 | 用户无需改系统设置也能减少动效 |
| 滚动进度写 width、页头滚动缩高度 | 进度用 scaleX，页头固定高度只保留分隔线 | 滚动时不改变文档布局 |

## 入口与行为

- 首页本期印样：胶片带。手动翻看，不自动播放，不接管纵向滚轮。
- 桌面：超过 7px 才判定拖拽；拖拽使用 pointer capture，结束有摩擦减速；下一次按下、滚轮、偏好变化或卸载会停止惯性。
- 触屏：使用浏览器原生横向滚动，保留纵向页面滚动。
- 胶片带获得焦点时：左右键翻格，Home / End 到两端；键盘操作立即反馈。
- 前后按钮在边界禁用；拖拽后抑制此次点击，正常点按仍进入作品详情。
- `/works` 保留真实链接、服务器搜索、分页与 URL 参数。只对返回结果做 FLIP，不用当前页数据冒充全站筛选。
- 灯箱支持首图、同组其他图片、方向键、主方向横滑、Esc；只有一张时禁用切图按钮。
- 页脚“减少动态效果”：关闭入场、位置过渡、拖拽惯性和平滑滚动，所有内容与操作仍可用。

## 时长与实现

- 标题揭示：860ms，两行相差 110ms。
- 封面落位：900ms；滚动入场：620ms，最多 5 级短错峰。
- FLIP：保留项 340ms、新项 260ms；初次网格 420ms，错峰 45ms。
- 灯箱：展开 380ms、切图 260ms、关闭 150ms。
- 日常控件沿用 120–260ms 的按下、hover 和状态过渡。
- 核心移动使用 transform / opacity；SVG 圈选保留描边动画。
- 静态版式与动效样式均集中在现有 `motion.css`，不建立第二套样式或动画框架。

## 代码位置

- `frontend/src/components/filmstrip.tsx`：胶片拖拽与控制。
- `frontend/src/components/animated-grid.tsx`：FLIP 网格。
- `frontend/src/components/motion.tsx`：WAAPI 入场、阅读进度、回顶、年份高亮、复制链接。
- `frontend/src/components/gallery.tsx`：整组灯箱、首图触发器和手势。
- `frontend/src/components/motion-preference.tsx`、`lib/motion.ts`：统一减少动效偏好。
- `frontend/src/app/motion.css`：动效、胶片外观和响应式规则。
