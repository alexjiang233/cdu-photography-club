# 2026-10-22 展示页调整

预览：`http://127.0.0.1:3000/field-journal#gallery-top`。原版首页仍在 `/`。

- 首屏沿用滚动照片墙，主标题改为更大的粗字重展示字体，加强遮罩对比；英文仍使用 Titillium Web。
- 大标题使用 Gallery Display；正文增加本地 Noto Sans SC 常用汉字字体（约 1.86 MiB，含 GB2312 和界面字形），避免缺少系统字体的设备将中文小字显示成宋体。许可证与字体一同保留。
- 首页相册采用黑色细框、相纸衬边和 7/5、5/7 错落构图；手机单列，保持照片原始比例。
- 首页活动改为三张日期卡，展示真实日期、地点及描述；活动内页用纵向日期索引和搜索，再接活动相册。未将年份不符的合影冒充为活动现场。
- 照片内页逐张浏览，提供当前页相册筛选及作者/图注/相册关键词搜索；分页仍由服务器提供。链接带 photo 参数，详情直接选中对应照片，保留 EXIF 信息和灯箱。
- 首页加入区使用深色邀请版面；独立加入页使用协会合影、基本信息、真实联系字段。二维码空缺时如实说明，不再展示申请表。
- 新版共用多栏大页脚；新增 `/field-journal/privacy`，复用现有隐私内容，并修正过时的 EXIF 删除说明。

验证：类型检查及生产构建通过；浏览器检查桌面、390px 和 320px；照片筛选与“合影 03”直达信息、搜索空状态、活动“人像”查找通过；新页面无横向溢出。二维码尚未提供。首页照片为现有真实相册，封面仍明确标注视觉样片。
