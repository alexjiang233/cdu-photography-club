# 当前版本产品复盘

## 用户反馈

用户体验后认为网站无聊、缺乏意义，AI 模板感明显。此前对功能架构的认可不代表对实际产品体验的认可。Logo 与真实内容仍未提供，但这不能用来解释或回避当前版本的产品问题。

## 产品判断

当前工程证明了一些功能能够运转，还没有证明摄影协会需要这个产品。页面齐全、技术完善、视觉规则统一，都不能单独构成访问与持续使用的理由。

当前首页主要依靠通用摄影文案与示例图片，没有呈现协会特有的人、作品、事件和关系。作品馆、资料库、活动报名等模块也没有围绕一个已确认的高频任务建立优势。它们目前更接近一份功能目录。

## 下一步的决策依据

后续重做前，需要由协会成员提供具体案例，确认：

- 最近一次找照片、交付照片、安排拍摄或整理资料时，发生了什么麻烦。
- 现在使用哪些工具，哪一步反复耗费时间，谁负责维护。
- 网站能否使某个任务明显更容易，且有真实成员愿意使用与更新。
- 如果网站消失，会有哪件事变得困难；如果答不出来，缩小甚至取消产品范围也是合理结论。

活动照片查找与交付、校园影像档案、拍摄任务协作都是待验证的方向，不是已确认需求。现在不应仅靠增加动效、卡片、AI 功能或改写口号来宣称解决了问题。

## 工程处理

保存当前前后端、数据模型、权限与验证记录，便于后续取舍。当前内容属于演示，生产依赖仍需部署验收；不会把现有工程标记为已成功上线的官网。

## 2026-10-19 改版记录

这一版不是"给旧页面加动效"，而是换了结构：

- 一级栏目收敛为六个：首页 / 作品 / 活动 / 成员 / 档案 / 加入；取消"关于"页，把介绍、成员、招新拆到各自的位置，减少套娃。
- 首页改为"协会当前状态"：收录数量、本期印样、近期活动、成员档案、年度档案。
- 作品保留原始比例，增加年度档案编号（`2026-006`）；活动分为即将开始/往期；档案允许"待归档"。
- 新增公开招新报名（表单 + 后台待审），这是此前完全缺失的入口。
- 参照 `rmultra.cn` 的结构原则（主体唯一、深浅分层、数据可核对），未复制它的站点导航、留言墙与数据墙。

仍未解决：真实素材（Logo、有人脸的活动照、成员自述、招新时间）；活动照片的批量交付；作者发布后的反馈回路；活动/资料/成员管理仍依赖 Django 原生后台。

验收记录见 [VERIFICATION.md](VERIFICATION.md)，设计规则见 [DESIGN.md](../DESIGN.md)。
